# Zachary Boston

CS student at NC State. Most of my work is in Rust and Python — I've been building language tooling, doing robotics on a real autonomous car platform, and picking up whatever else the coursework throws at me.

---

**[rust-interpreter](https://github.com/Znboston/rust-interpreter)** — Functional language interpreter written in Rust. Handles lexical and dynamic scoping, mutable cells, block expressions, and a static type checker that runs before evaluation.

**[self-driving-car-projects](https://github.com/Znboston/self-driving-car-projects)** — ROS 2 work on the Wolfwagen, a 1:10 scale autonomous car with a Jetson Orin, ZED 2i stereo camera, and CAN bus motor control. Projects go from basic teleoperation to CV-based lane following with PID and a full autonomous box-sorting mission.

**[cxport](https://github.com/Znboston/cxport)** — CLI for exporting conversations out of AI chat platforms.

**[ESTVP](https://github.com/Znboston/ESTVP)** — Interactive climate data dashboard with animated choropleth maps and linear regression predictions.

**[service-suspended](https://github.com/Znboston/service-suspended)** — Four-episode game series for a game design course. Starts as Twine interactive fiction and ends as a Godot 4 puzzle-combat game.

**[ee-lab-dashboard](https://github.com/Znboston/ee-lab-dashboard)** — Overview of a full-stack lab management platform built as a capstone. Django REST backend, Next.js frontend, PostgreSQL, Docker with isolated dev/test/prod environments.
